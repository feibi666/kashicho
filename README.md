# 歌詞帳

手机上学日语歌用的注音歌词本 + 本地播放器。

授权手机里的音乐文件夹 → 播歌同时给歌词汉字标假名 → 点句子看中文 → 单句循环慢速跟唱。
音频和标注全部留在本机，不上传、不联网同步。

纯静态单页应用，无框架、无构建。

线上：`https://feibi666.github.io/kashicho/`

## 功能

- **自动注音**：kuromoji + IPADIC 给汉字词标假名，假名部分不标
- **四层读音优先级**：本歌人工注音 > 歌词自带 `宇宙(そら)` > 逐句读音表 > 分词器
- **人工注音按歌存**：多音词在不同歌里读音不同，互不串味；可选「同时套用到其他歌」
- **逐句译文**：点句子展开；「译」一键全展开
- **查词面板**：双击句子 → 复制纯原文 / 标读音 / 加释义，三个 tab
- **生词释义**：词下方赭橙小字，不占正文宽度、不进剪贴板
- **读本地音乐**：`showDirectoryPicker()` 授权文件夹，只读不复制，递归扫三层
- **网易云 `.ncm` 直接播**：本地解密，不转档
- **自动对轴**：贴网易云分享链接，一次拿齐时间轴 + 官方译文
- **打点校时**：播着歌逐句点按，自动跳下一句，可 ±0.1 微调
- **播放控制**：上一首/下一首、队列、顺序/列表循环/单曲循环/随机、`1×`/`0.75×`
- **单句循环**：反复磨一句
- **锁屏 / 通知栏控制**：MediaSession，支持锁屏拖动进度
- **备份 / 恢复**：导出 JSON，换机不丢歌词
- **离线可用**：PWA，Service Worker 缓存外壳与词典

## 使用前提

必须用 **Chrome / Edge 安卓 132+**，且通过 **HTTPS** 访问（`showDirectoryPicker()` 与 Service Worker 在 http 下都不可用）。其他浏览器或 WebView 壳会退化成「临时选几首歌」。

## 部署

无需构建。把本目录所有文件推到任意静态托管根目录即可，例如 GitHub Pages。

## 数据存放

歌词、读音、释义、播放位置全部存在**使用者浏览器本地**（IndexedDB `kashicho`），不上传。音乐文件始终留在本地磁盘。换手机或清站点数据会丢，用「备份」导出即可。

仓库内不含任何歌曲歌词。
