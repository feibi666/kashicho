# 歌詞帳

手机上学日语歌用的注音歌词本。粘贴歌词 → 汉字词自动标注假名 → 点句子看中文译文 → 跟着本地音频跟唱。

纯静态单页应用，无框架、无构建，三个文件即可运行。

## 功能

- **自动注音**：用 kuromoji + IPADIC 词典给汉字词标假名，平假名/片假名不标
- **三层读音优先级**：歌词自带括号读音 > 本首歌的读音例外表 > 词典
- **逐句译文**：点一下句子，译文在下方展开
- **读取本地音乐**：通过 `showDirectoryPicker()` 授权文件夹，只读不复制
- **播放控制**：上一首/下一首、顺序/列表循环/单曲循环/随机
- **打点校时**：按播放键卡拍点，自动跳到下一句
- **单句循环**：反复听同一句
- **离线可用**：PWA，Service Worker 缓存外壳

## 使用前提

必须通过 **HTTPS** 访问。`showDirectoryPicker()` 与 Service Worker 在 http 下都不可用。

## 部署

无需构建。把本目录所有文件推到任意静态托管的根目录即可，例如 GitHub Pages。

## 数据存放

歌词、读音例外、播放位置全部存储在**使用者浏览器本地**（IndexedDB），不上传、不联网同步。音乐文件始终留在本地磁盘。

仓库内不含任何歌曲歌词。
